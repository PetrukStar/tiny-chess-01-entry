**Pocket Knight** — a chess engine in under 4 KB of Python. Negamax alpha-beta search with null-move pruning, late-move reductions, check extensions and quiescence; tapered piece-square tables and MVV-LVA move ordering with a transposition table, playing the make.fun house gauntlet through the env API. Deterministic: a fixed node budget per move, no clock, no randomness. Built from a readable Python source and packed into the single-file `main.py` with `makefun compress`.
